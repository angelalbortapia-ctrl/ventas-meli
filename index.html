☁️ Sync Supabase (Mac ↔ iPhone)

Recomendado: abre esta PWA en Safari → Compartir → Añadir a pantalla de inicio. No hace falta App Store. Necesitas hospedar la app en HTTPS (GitHub Pages, Netlify, etc.) y el mismo login en ambos dispositivos.
Sync sube Mercado Libre y Amazon juntos. Si hay conflicto, verás el conteo de ambos catálogos.

  1. Crea un proyecto en supabase.com
  2. SQL Editor → pega y ejecuta supabase/schema.sql
  3. Project Settings → API → copia URL y anon key aquí
  4. Crea cuenta / inicia sesión con el mismo email en Mac e iPhone
  5. iPhone: abre la URL publicada (GitHub Pages) en Safari → Compartir → Añadir a pantalla de inicio

iPhone (Safari, no el ícono de inicio): 1) Limpiar caché → 2) Instalar datos (archivo AirDrop o nube).

Si lo apagas, la ficha no consulta Keepa. Puedes seguir investigando cualquier ASIN desde Keepa Lab.

La extensión Premium de Keepa no incluye la API: necesitas la key en keepa.com/#!api. Corre la app con python3 serve.py (proxy CORS). Con ASIN, verás precio/BSR en Ofertas y Productos.

SerpAPI (Shopping + Immersive MX)

Sin configurar.

Usado en Ofertas: Google Shopping + Immersive Product (todas las tiendas del mismo ítem). ~2 créditos por investigación. Key en serpapi.com. Requiere python3 serve.py. Alternativa: variable de entorno SERPAPI_KEY.

Tarifas Amazon México

La Calculadora de ingresos aplica el % de referido sobre el precio sin IVA (precio ÷ 1.16), luego el mayor entre ese monto y el mínimo ($8). FBA depende del precio (<$150 / $150–299 / $299–499 / ≥$499), tamaño y peso. El almacenamiento FBA se captura por producto (campo en Precios).
